# A student's first day — Jenni and Thesis Copilot, step by step (2026-10-04)

Read from the pages themselves (accessibility tree and page text, not only screenshots), on the same
thesis topic in both tools: soil organic carbon in restored and natural mangroves at Pichavaram,
Tamil Nadu. Jenni on the owner's free account; ours on the dev stack with real models. Each step
says what the student sees, what they must do, and what can go wrong.

## Step 0 — Finding the tool

| | Jenni | Ours |
|---|---|---|
| Home page | One promise ("Meet Your Intelligent Research Assistant"), one button "Start writing – it's free", "Loved by over 6 million academics", then the real editor **animating**: a chat answer writes itself with citations | "A thesis editor that only cites papers you've read", "Made for master's and PhD students in India", two buttons, "14-day free trial, no card · Nothing deleted if you stop paying", then a stock photo with one evidence card |
| Signed-in visitor | The app is a separate address; opens the last document | Sees the sales page again |

## Step 1 — Signing up

| | Jenni | Ours |
|---|---|---|
| Screen | "Get started with Jenni": Continue with Google, or name + email + password, "Start for free"; a language picker; terms notice | "Create your account": email → a six-digit code by email creates the account; "I would rather choose a password"; what the 14-day trial includes; Google when configured |

## Step 2 — What they see first

| | Jenni | Ours |
|---|---|---|
| First screen | A new document opens as the start screen: a prompt box whose placeholder types examples; a meter from "Weak prompt" to "Great prompt"; "Import from Word"; "Skip and start writing"; Explore cards (Chat with AI, Upload Sources) | "Your theses": trial banner, a working-title box, "a paper I have written / a topic", Create thesis |
| Returning later | Straight back into the last document | The same dashboard; each thesis card has 10 links (Proposal, Sources, Outline, Build, Review, Submit, Journals, Viva, Write, Delete) |

## Step 3 — Setting up the thesis

| | Jenni | Ours |
|---|---|---|
| Steps | (1) prompt with meter → (2) one screen of citation chips (style, web/library, year, impact factor, cited-by, preprints) → (3) headings: IMRaD / AI headings / none → "Start Writing" | (1) title + path → (2) proposal conversation: up to 3 questions (typed answers to numbered options) → (3) skeleton: problem statement, objectives, gap → "Continue to the editor" |
| Time | ~1 min to a document with every heading and per-section notes | ~2 min to a proposal; the outline is a separate page and button ("Generate outline") the student may never see |
| Quality | Notes per heading picked up the student's own argument | The research questions and gap are far stronger than anything Jenni produces |
| Faults seen | — | Related work "0 found" (the search sends the whole message; key words find 465) yet the gap text claims related work was found; "See the sources found in your paper" on the topic path |
| Change later | Document settings panel: prompt, sources, filters, style, font | Outline page (language, template, chapters), Settings page, Sources page |

## Step 4 — The first sentence

| | Jenni | Ours |
|---|---|---|
| Lands | Cursor in the Introduction; a cited suggestion appears in ~15 s with Accept / Refine / thumbs and an evidence card on hover | Chapter 1 only, under two banners; nothing appears; Ctrl+/ and Suggest do nothing visible (no papers yet); automatic sources add papers in the background but the open panel still says "No papers yet" |
| Accept | → or the Accept button (works on a phone) | Tab or → only (no button; a phone cannot accept) |
| Shape a suggestion | Refine: presets (stay on topic, complete paragraph, novelty, simplify, no citations, validate evidence, cite from my library) or a typed prompt; arrows through earlier versions | Shift+→ and a typed instruction |
| What counts | Only accepted suggestions count (10 a day free) | Every suggestion shown counts, kept or dismissed (50 a month on the trial) |

## Step 5 — Finding papers

| | Jenni | Ours |
|---|---|---|
| Where | A panel beside the text; a suggested query from the document | A separate Sources page (Discover tab) |
| Speed | ~3 s | ~80 s, "Searching…" only |
| Each result | Type, cited-by, impact factor, open access, the matching passage, Cite / Open quote / Save | 70 candidates in 7 themes (open gap / active area, trend line); tick, "Add to library", go back |
| Also | "Find citations" on a selected sentence (but cancelling leaves a stray "@") | Cite suggestions from the library for a selected sentence |

## Step 6 — Writing on

| | Jenni | Ours |
|---|---|---|
| Insert | "/" menu: headings, lists, table, image, equation (LaTeX / describe in words / from a picture, with examples), chart, table of contents, AI declaration, placeholder citation; Markdown typing shortcuts; a KaTeX cheat sheet of 23 patterns | Toolbar: formatting, tables, footnote, image, inline and display equation (one LaTeX line, "E = mc^2"), chart, diagram |
| Edit a passage | Select → Find citations, AI Chat, AI Edit (17 actions), Comment, Review; the edit is a preview with "what changed and why", Replace / Insert below / Try again / Discard | Select → 5 commands; the result is a draft block to accept |
| Section guidance | A side panel of notes per heading, each with sources to pin and Generate | "What this chapter is for" banner per chapter; pins per chapter |
| Ask | Chat with Web / Library / Current document, each Off/Ask/On; agentic (~90 s), shows steps, asks before the web | Chat over the library only (~2 s), Library / This thesis / Find papers |

## Step 7 — Checking the work

| | Jenni | Ours |
|---|---|---|
| Where | One Review panel, five buttons: Claim confidence, Peer Review, Source quality, Tone of voice, Proofread | Flags tab, Review tab (the guide cycle), coherence run, proofreading, citation report, originality, Submit |
| Peer review | Agent with its own searches; 1 min 35 s; scores (soundness, presentation, contribution, /10), weaknesses, strengths, questions for the authors, 24 comments anchored to sentences (Major/Minor) | Examiner review only inside a chapter build; viva questions on the Viva page |
| Accepting fixes | Tracked changes; Y/N keys; Accept all | j/k/a/e/r keys on the guide's comments; individual flags |

## Step 8 — The supervisor

| | Jenni | Ours |
|---|---|---|
| Sharing | Free: Restricted / anyone with the link only (no invite by email); paid: Editor / Commenter / Viewer, live cursors | Share with the guide; comments; scoped revisions; a review queue with keyboard triage; paste emailed feedback or upload a marked-up .docx; a response-to-committee table; progress view for supervisors |

Ours is far ahead here; Jenni added commenter/viewer roles only on 2026-09-23 and pitched them at
supervisors.

## Step 9 — Submitting

| | Jenni | Ours |

## The shape of it

Jenni's first day is **short and continuous**: four screens to a cited sentence, everything else in
panels beside the text, defaults everywhere, progress shown at every wait. Ours is **deeper but
broken into pages**: a stronger proposal, a far better supervisor and submission path, but the
student reaches a first cited sentence only after leaving the editor, and several screens show our
own internal names and stale words.
